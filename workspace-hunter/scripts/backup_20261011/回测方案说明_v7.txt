MA60偏移率回测方案说明与结果总览（2026-10-11 最终版）

【共同框架】
偏移率 = (收盘价 − MA60) / MA60 × 100%，MA60为60日简单移动平均。
收盘判断信号、收盘价成交（无未来函数）；一轮 = 买入（含各层补仓）到一次性全部卖出；未平仓轮不计入统计；不复利；单位本金1万元。
卖出条件全部相同：偏移率回到 ≥ 0% 时一次性清仓。
回测区间：2010-01-04 至 2026-10-09（创业板2010-06起、恒生科技2014-12回溯起、科创综指2019-12起，其余2010起）。

【买入阈值来源】
每个指数的基准阈值 neg80 = 该指数MA60偏移率"下跌80%分位线"（2023基线/近三年，负偏移日的20%分位数），来源：
- 国内7指数：取自 Bias with turnover_warning_push.py 程序口径
- 国际3指数（纳指/道指/恒生）：取自 international_Bias_for_any_index_warning_push.py 程序口径
- 恒生科技：取自 ETF_warning_push.py 程序中513180恒生科技ETF口径（-8.01%）
- 日经225：取自 ETF_warning_push.py 程序中513880日经ETF口径（-3.99%）

各指数 neg80：上证-3.85%、沪深300 -4.53%、中证500 -5.93%、中证1000 -6.75%、红利-4.29%、创业板-7.88%、科创综指-8.21%、纳斯达克-5.75%、道琼斯-3.78%、恒生-5.23%、恒生科技-8.01%、日经225 -3.99%

【五种方案定义】

方案① 单层
偏移率 ≤ neg80 → 收盘价买入1份（1万元）；偏移率 ≥ 0% → 全部卖出。单轮最大本金1份。

方案② 等额加仓 1:1
偏移率 ≤ neg80 → 首买1份；进一步 ≤ neg80×1.5 → 加仓1份（等额）；≥ 0% → 清仓。单轮最大本金2份。

方案③ 金字塔加仓 1:2
偏移率 ≤ neg80 → 首买1份；≤ neg80×1.5 → 加仓2份；≥ 0% → 清仓。单轮最大本金3份。

方案④ 三层金字塔 1:2:3
偏移率 ≤ neg80 → 首买1份；≤ neg80×1.5 → 加仓2份；≤ neg80×2.0 → 再补3份；≥ 0% → 清仓。单轮最大本金6份。

方案⑤ 四层金字塔 1:2:3:4
偏移率 ≤ neg80 → 首买1份；≤ neg80×1.5 → 加仓2份；≤ neg80×2.0 → 再补3份；≤ neg80×3.0 → 再补4份；≥ 0% → 清仓。单轮最大本金10份。

通用规则：首日同时深破多层阈值则同日连买多层；轮收益 = 各份收益率 × 金额权重之和；总收益% = 各轮收益简单加总（单位本金1万）。
