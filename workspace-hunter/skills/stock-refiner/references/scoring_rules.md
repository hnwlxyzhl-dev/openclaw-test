# 评分与判定细则（stock-refiner）

## 一、股票类型判定（三层证据）

### 判定顺序与规则
1. **周期股判定**（优先级最高）：满足以下任一即标"周期嫌疑"：
   - 量化：`boom_bust_signature=true`（曾有yoy>+50%且yoy<-30%年份）
   - 量化：`netprofit_cv_5y > 0.8`
   - 量化：`gross_margin_range_5y > 15`（pct）
   - 量化：`latest_np_yoy_over_rev_yoy > 2.5` 且 L3搜索证实产品涨价驱动
   - 行业：industry 命中 cyclical 池
   - **规则：周期嫌疑证据≥2条 → 剔除；恰好1条且行业属成长池 → AI搜索主营产品价格走势后个案裁定**
2. **价值股判定**：同时满足 → 剔除：
   - `rev_cagr_3y < 10` 且 `rev_cagr_5y < 10`
   - ROE序列平稳（5年极差<5pct）无上行斜率
   - 行业命中 value 池 或 兜底rule3
3. **其他剔除**：营收负增长趋势（`neg_rev_years_5y>=2`）、纯题材、困境反转（前年深亏今年高增）
4. **成长股**：通过以上排除 + `rev_cagr_3y>=15`（或近3年营收yoy逐年>15%）+ 无负增长年 → 保留
   - 成长但`rev_cagr_3y`在10~15%之间：标"弱成长"，仅在财务评分≥8时保留

### 置信度标注
- 高：行业池+量化特征一致（如成长池行业+无任何周期签名）
- 中：量化清楚但行业池未命中（图谱外）
- 低：证据冲突经个案裁定

## 二、财务状况评分（10分制，≥7通过）

| 维度 | 权重 | 指标与得分/扣分 |
|------|------|----------------|
| 盈利质量 | 3.0 | 扣非/归母>0.8(+1)；OCF/净利TTM>0.8(+1)；毛利率近4季平稳或上行(+1)；任一不满足按比例扣 |
| 增长质量 | 2.5 | 营收yoy≥20%(+1)；净利增速/营收增速在0.8~2.5(+1)；单季环比未恶化(+0.5) |
| 资产负债表 | 2.0 | 负债率低于行业均值(+0.5)；应收增速<营收增速(+1)；货币资金覆盖短债(+0.5) |
| 现金流 | 1.5 | OCF连续4季为正(+1)；FCF转正或亏损收窄(+0.5) |
| 造假红旗 | 1.0 | 基础分1分，命中红旗逐项扣光 |

**红旗清单（一票否决项单独标注）**：
- 应收+存货增速双>营收增速 且 OCF恶化 → 扣1并标红旗
- 大存大贷（货币资金高同时短债高，利息收入与资金不匹配）→ 标红旗
- 商誉/净资产>30% → 标红旗
- **两项红旗命中 → 直接否决，不进终选**

行业均值参考：机械设备~55%、食品饮料~35%、医药~40%、电子~55%、电力设备~60%（负债率），无数据时用通用50%分位。

## 三、未来盈利方向评估（L1>L2>L3）

### L1 公司自身前瞻信号（权重最高）
来自**最新财报原文**（PDF精读，非二手解读）：
- MD&A经营计划/行业展望：明确扩产、新订单、增长指引 → ↑证据
- 合同负债/预收款环比（+30%以上=强↑，-20%以下=强↓）
- 在建工程同比+资本开支趋势（真金白银扩产=管理层对需求投票）
- 存货结构：原材料备货↑（预示排产↑）vs 产成品积压（需求弱）
- 下期业绩预告（若有，最新鲜）

### L2 卖方一致预期
- 近90天券商EPS预测**修正方向**：≥2家上调→支持↑；≥2家下调→支持↓；分歧→中性
- 绝对值仅参考，修正方向是核心

### L3 行业景气
- 产品价格/排产/中标/政策
- 行业景气与公司增速背离 → 整体降置信度

### 定向规则
- L1+L2同向 → 该方向，高置信
- L1、L2打架 → 取弱方向，低置信
- L1缺失（财报无前瞻披露）→ 仅靠L2+L3，最高"中置信"
- **方向=↓ → 剔除；方向=→（平稳）→ 仅当财务评分≥8.5保留；方向不明 → 剔除**

## 四、终选与报告

- 通过线：类型=成长 + 财务≥7 + 方向=↑（或→且≥8.5）+ 无双红旗
- 每只入选股必须给出：行业类型、类型判定依据（量化数字）、财务分维度得分、方向证据链（标注来源：财报原文/领先指标/卖方/行业）、估值、风险
- 每只剔除股必须给出：行业类型 + 具体触发规则（可复核的数字/事实）
- **空精选不是失败**：完整输出所有股票的排除理由

## 五、四面评估（技术/资金/消息/政策，2026-08-20新增）

### 定位（重要）
- **四面不掺和基本面评分**：选股门槛仍是"类型=成长 + 财务≥7 + 方向↑"；四面是仪表盘——技术/资金管**择时**，消息管**风险否决**，政策管**行业beta**
- 范围：技术面+资金面 → **全池股**（脚本，零搜索配额）；消息面+政策面 → **仅成长股**（需搜索）

### ① 技术面（fetch_technical.py，tushare daily+adj_factor手工前复权）
- 数据：5年日线 → MA5/10/20/60/120/250、MACD、RSI14、KDJ、BOLL(20,2)、52周/5年分位、量价形态、支撑压力位（均线粘合带自动识别）
- 评分（0-10）：
  - 趋势(4)：站上MA60且MA60二十日斜率>0 +2 ｜站上MA250 +1 ｜MA5>MA10>MA20 +1
  - 动量(2)：MACD DIF>DEA或绿柱连续收窄 +1 ｜RSI14∈[40,65] +0.5 ｜KDJ低位(D<40或K上穿D且K<50) +0.5
  - 位置(2)：52周分位∈[30,70] +1 ｜距52周高点回撤<15% +1
  - 量价(2)：缩量回调/放量上行 +1.5 ｜无量价背离 +0.5（缩量上涨/放量下跌=警惕，+0）
- **用途：输出择时建议**——左侧买点=第一/第二支撑位区间；右侧触发=放量站回MA20或MACD绿柱收窄。**不否决选股**；技术面破位（跌破核心支撑）仅作风险标注

### ② 资金面（fetch_capital.py，tushare moneyflow/两融/股东户数/大宗/解禁 + 东财龙虎榜）
- 评分（0-10）：
  - 主力资金(4)：近10日主力(特大+大单)净流入>0 +1.5 ｜近5日较前5日改善 +1 ｜资金-价格无背离 +1 ｜净流入>流通市值0.3% +0.5
  - 杠杆(1.5)：融资余额20日变化∈[-5%,+15%] +1.5 ｜(15,25]% +0.5 ｜>25%过热或<-10%退潮 → 0分+警示
  - 筹码(1.5)：**股东户数趋势判定（老板要求优选下降趋势，2026-08-20）**——最近5期（月度/季度按实际披露频率）：连续≥2期下降(筹码集中) +1.5 ｜仅最新一期下降 +1 ｜无下降趋势 +0；5期累计升幅>20%加警示"明显分散(散户进场)"
- **优选规则：多只入选时，股东户数下降趋势（consecutive_down_periods大者优先）作为排序依据之一**；户数趋势不构成硬性否决
  - 事件(3)：基础3分；大宗折价>5% -1 ｜未来12个月解禁>流通盘5% -1 ｜近60日龙虎榜上榜 -1
- 警示（不扣分单独标）：流入价跌=吸筹嫌疑｜流出价涨=出货嫌疑｜两融过热/退潮
- **用途：择时+风险标注，不否决选股**（解禁/大宗警示写进报告风险行）

### ③ 消息面（fetch_news_signals.py收集事实 + AI判断，仅成长股）
- 数据层（脚本，免费）：近30天公告关键词分类（利好:回购/增持/中标/预增/分红/激励等；利空:减持/质押/诉讼/立案/问询/预减/非标等）+ 事件日历（财报预约日/解禁日）
- AI层（搜索≤2次/股）：近7天舆情+负面关键词扫描
- 评分（0-10，AI综合判定）：无利空+有近期(≤7天)利好 8-10 ｜无利空无利好 6-7 ｜有轻利空(减持<1%/问询已回复) 4-5 ｜有利空 0-3
- **消息新鲜度铁律：每条消息必带日期，>7天默认已消化**（2026-05-08教训固化）
- **硬否决（一票否决，直接出局）**：立案调查｜业绩暴雷(预减>50%/首亏)｜审计非标意见
- 解禁事件>流通盘5% → 强制风险标注

### ④ 政策面（AI搜索，仅成长股，≤2次/股）
- 搜索："{行业关键词} 政策/规划/补贴 2026"；**出口型企业必查贸易政策**（industry_map.json 的 trade_sensitive 池命中 或 最新财报海外营收占比>30%）
- 评分（0-10，AI判定）：明确支持(补贴/规划/采购目录) 8-10 ｜中性/无直接政策 5-7 ｜压制(限制/收紧/贸易摩擦升级) 0-4
- 输出：政策清单（名称+发布日期+影响路径：需求/成本/准入）+ 近90天边际变化方向
- **方向=压制 → 强制降综合评级一档并在报告显著标注**（不直接否决，除非与基本面方向↓叠加）

### 四面整合规则
1. 基本面门槛（财务≥7+方向↑）不变 → 入选
2. 消息面硬否决（立案/暴雷/非标）→ 出局
3. 政策面压制 → 综合评级降一档（如"推荐"→"观察"）
4. 技术/资金面 → 仅影响"择时建议"行和风险标注，不影响入选
5. 报告新增四行仪表盘 + 择时建议行（模板见SKILL.md Step 5）

## 六、信息客观性与时效标准（2026-08-20老板要求，硬规则）

### 反臆想三问（每条事实性陈述引用前自检）
1. **从哪来？**——脚本输出/财报PDF原文/公告原文/搜索命中，四者之一。AI记忆不算来源
2. **什么时候的？**——必带日期。无日期的搜索结果不得引用（无法判断时效）
3. **原文说的是这个意思吗？**——引用不得脑补、不得外推、不得把"公司说"改成"事实是"

### 禁止行为清单
- ❌ 用训练记忆填充公司近况（"印象中它最近拿了订单"→必须先搜到带日期的来源）
- ❌ 把搜索结果的只言片语扩展成具体数字（结果说"增长"→不得写成"增长30%"）
- ❌ 无日期信息当作新鲜催化（>7天默认已消化，见SKILL.md铁律10时效表）
- ❌ 搜索无果时编造"未发现重大利空"以外的结论（只能写"未发现"，不得写"确认无"）

### 时效降级阶梯（与SKILL.md铁律10同步）
- 消息/公告：>7天标"已消化"；消息面统计窗口30天
- 券商观点：>90天只作背景；引用必带机构名+日期
- 政策：>12个月标"存量政策(现行有效)"；边际催化只认近90天
- 行业数据：>90天降级背景参考
- 所有过期信息仍需引用时，必须显式标注日期+时效状态，禁止与新鲜信息混排不区分
